Step 1

Report language

Everything the model writes comes back in this language — the suggested angles below as well as the finished reading. It takes effect on the next call, so a document already scanned keeps the angles it came back with; hit Re-suggest to redo them in the new language.

Step 2

Suggested focus

Nothing is sent until you ask for it. Press Suggest focus angles and the model reads each uploaded document, works out what it is and guesses what you would want to learn from it. Tick the angles you want — each one becomes an extra section in the analysis, alongside the sections below.

Model & API

Model configuration

Works with third-party cloud models and with a local Ollama. Your API key is stored only in this browser.

PDF pages and uploaded images reach the model as images, so reading those requires a vision-capable model — a text-only model returns empty sections. Word, Markdown and plain-text documents are sent as text and work with any model. The model picker groups models by provider and marks the text-only ones.

Connection

Endpoint and model

Every save is recorded here, so you can switch back to any model you have used before.

This model has no vision input. It can read Word, Markdown and plain-text documents, but PDF pages and images will come back empty — those are sent to the model as page images. Pick a vision-capable model from the list to read them.

Local Ollama: the URL is usually http://localhost:11434 and no API key is needed. Use Fetch models to list the models you have pulled. If that fails, start Ollama with OLLAMA_ORIGINS=* so the browser is allowed to reach it. Reading figures and equations requires a vision-capable model such as llama3.2-vision or llava.
