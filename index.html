Settings

Model configuration

Works with third-party cloud models and with a local Ollama. Your API key is stored only in this browser.

Every page is rendered to an image before it reaches the model, so the model has to accept image input. Text-only models return empty sections. The model picker lists vision-capable models grouped by provider.

Connection

Endpoint and model

Every save is recorded here, so you can switch back to any model you have used before.

Local Ollama: the URL is usually http://localhost:11434 and no API key is needed. Use Fetch models to list the models you have pulled. If that fails, start Ollama with OLLAMA_ORIGINS=* so the browser is allowed to reach it. Reading figures and equations requires a vision-capable model such as llama3.2-vision or llava.
