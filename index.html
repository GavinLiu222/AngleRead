大模型配置

支持第三方云端大模型与本地 Ollama。API Key 仅保存在本机浏览器中。

保存配置后会自动记录到这里，可随时切换之前用过的模型。

本地 Ollama：URL 一般为 http://localhost:11434，无需 API Key。点「获取模型」可列出已下载的模型。 若获取失败，请在启动 Ollama 前设置环境变量 OLLAMA_ORIGINS=* 以允许浏览器访问。图文分析需选用支持视觉的模型（如 llava、llama3.2-vision）。
